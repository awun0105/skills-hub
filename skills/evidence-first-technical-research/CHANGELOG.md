# Changelog

## 2.0.0 — Complete evidence-first research and tutor workflow

- Preserve the original research, paper/code/math verification, anti-hallucination gates, claim ledger and cold-read recovery.
- Add outcome-oriented curriculum planning with prerequisite DAG, stable IDs, milestones and source-verification plans per lesson.
- Add verified first-principles lesson production, derivation and visualization rules, misconception handling, objective-aligned assessment and learner adaptation.
- Add separate learner progress state (delivery vs demonstrated proficiency), dependency-aware correction protocol, and portable cross-agent course handoff.
- Add curriculum/learner-state JSON templates and structural validator with regression tests.
- Expand agent adapters, installation instructions, output templates and adversarial acceptance scenarios.

**Important:** The bundle's validators check structural consistency only. They do not validate factual truth or that an agent performed research, and installing the skill does not grant tools or persistent storage.
