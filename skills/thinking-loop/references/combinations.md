# Eight illustrative combinations

TD = top-down; BU = bottom-up; DIV = divergent; CON = convergent; S = shallow; D = deep.
These eight full combinations are examples in a design grid, not all human thinking,
not a proven psychological taxonomy, and not all possible task sequences. A stage
can omit direction or breadth. Depth controls rigor, not option count or answer size.

| State | Useful operation | Expected artifact | Change course when |
| --- | --- | --- | --- |
| (TD, DIV, S) | Sketch different structures from a known goal. | A few distinct provisional architectures, key unknowns. | User needs a choice, or a decisive uncertainty needs verification. |
| (TD, DIV, D) | Develop distinct designs and their interacting assumptions. | Alternative mechanisms with dependency/failure analyses. | Evidence is needed, or requested idea coverage is complete. |
| (TD, CON, S) | Refine/select a familiar low-risk plan against known criteria. | Lean plan and acceptance checks. | A presumed prerequisite fails or the next action is consequential. |
| (TD, CON, D) | Compare architectures with system-wide requirements. | Supported decision, sensitive assumptions, integration checks. | No design survives or a critical fact is missing. |
| (BU, DIV, S) | Triage observations and propose plausible different explanations. | Observations, a small hypothesis set, first discriminator. | Evidence distinguishes candidates or uncertainty has serious consequences. |
| (BU, DIV, D) | Investigate anomalies and develop empirical mechanisms. | Scoped evidence, alternatives, controlled discriminating tests. | Hypotheses can be tested or ideas-only output is complete. |
| (BU, CON, S) | Resolve a bounded observed issue using a direct check. | Scoped supported explanation or honest evidence gap. | The direct check fails or critical ambiguity persists. |
| (BU, CON, D) | Test live explanations rigorously against measurements. | Supported cause/choice, counterevidence, validity limits. | Required checks pass, integration remains, or no permitted check can proceed. |

## Composition rules
Shallow divergence still produces several possibilities; it does not force a winner.
Deep convergence verifies existing options; it does not automatically add more.
Top-down and bottom-up can alternate within a useful check rather than becoming
separate nested workflows. Ideas-only output is terminal when it is the deliverable.
The implementation phase needs its own risk assessment even after a design is settled.

## Example, not an executed investigation
For collider drift, initially inspect same-pose output and sketch causes (BU, DIV, S).
Test the live mechanisms (BU, CON, D). Update the shared transform contract and
integration tests (TD, CON, D or S according to actual impact). Do not presume the
cause, the test outcome, or permission to modify production.
